pubmy hanya mengonversi file yang bebas kamu konversi. E-book MOBI atau AZW3 yang dilindungi DRM ditolak dan tidak pernah didekripsi. Hal yang sama berlaku untuk EPUB ber-DRM: pubmy tidak membukanya. pubmy tidak menyertakan, tidak menjalankan, dan tidak merekomendasikan alat penghapus DRM apa pun.

## Yang terjadi pada file ber-DRM

Di situs web, file itu tidak masuk ke hasil. Barisnya menampilkan pesan:

- Untuk MOBI atau AZW3: "File ini dilindungi DRM, jadi tidak bisa dikonversi."
- Untuk EPUB yang kamu buka untuk dibaca: "EPUB ini dilindungi DRM, jadi tidak bisa dibuka."

Di [CLI](/cli/), file itu tercatat di laporan dengan kode `DRM` dan tidak menghasilkan EPUB. Skill agen diberi instruksi untuk tidak pernah mencoba ulang atau mengakali penolakan DRM.

## Alasannya

DRM adalah kunci yang membatasi siapa yang boleh membuka sebuah file. pubmy hanya bekerja dengan file yang bebas kamu konversi, jadi file yang terkunci dibiarkan apa adanya: pubmy tidak membuka kuncinya dan tidak membantu membukanya.

## Yang bisa kamu lakukan

- Pakai salinan tanpa DRM. Banyak toko buku menjual EPUB tanpa DRM, dan banyak perpustakaan domain publik menyediakan EPUB tanpa DRM.
- Kalau kamu sudah punya EPUB tanpa DRM, file itu tidak perlu dikonversi. Kamu bisa membukanya di pubmy untuk dibaca, atau langsung mengirimnya ke Kindle.
- Lihat [Format](/format/) untuk daftar file yang bisa dikonversi, dan [FAQ di Panduan](/panduan/#faq) untuk pertanyaan lain.
