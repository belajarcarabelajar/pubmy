This page lists what changed between versions of pubmy. The website runs version {{VERSION}}. For the agent skill and CLI, see [Skill and CLI](/en/cli/).

## v0.2.0 (2026-11-14)

- A dark theme that follows your device setting, and a More actions menu on the page.
- A new logo, the supported formats listed in the drop zone, progress for the whole queue, and Download all (ZIP) to save every ready EPUB at once.
- Preview: a Contents list to jump between chapters, and a Full screen button on tablets and phones.
- A dropped EPUB opens in the reader instead of being converted, and Read opens it again.
- The page appears in your language straight away when you reload it, and a long language label no longer squeezes the header.
- PDFs: cleaner running headers and a cleaner table of contents.
- Fixes from an audit on 2026-11-09 in the format readers, the PDF reader and the CLI.
- The OCR language data now ships inside the skill, so scanned PDFs need no download, and every release ZIP is checked before it is published.

[v0.2.0 on GitHub](https://github.com/belajarcarabelajar/pubmy/releases/tag/v0.2.0)

## v0.1.0 (2026-11-07)

- The first release: documents, ebooks and comics to EPUB for Kindle, on the website in your browser and as an agent skill and CLI.
- EPUB preview on the website.
- PDFs: running headers removed, figures kept as images, and tables printed sideways rebuilt as tables.
- Formulas and line diagrams in PDFs kept as pictures of their area of the page. Formulas, problem lines and captions are not treated as headings.
- Website: a better preview on phones, page arrows, a drop hint, and accessibility fixes from an audit.
- Faster loading, because each format reader loads only when it is needed.
- Install methods for the skill: one command, the ZIP download, a copy into one project, and how to uninstall.

[v0.1.0 on GitHub](https://github.com/belajarcarabelajar/pubmy/releases/tag/v0.1.0)

All releases, with the full list of changes, are on [GitHub](https://github.com/belajarcarabelajar/pubmy/releases).
